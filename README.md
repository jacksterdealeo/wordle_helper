<h1 align="center">Wordle Helper</h1>
This is a tool for helping you discover possible Wordle solutions. It shows remaining words based on letters you guessed.

## Usage

Run with the latest Python 3 in a terminal. Commands are listed when you use use the help command. Type the command, then answer the prompt.

## Commands

- help: shows this message

- list: shows remaining words

- exit: exits the script

- green: add green letters

- orange: add orange letters

- black: add black letters
